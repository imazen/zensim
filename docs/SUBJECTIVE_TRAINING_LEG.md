# Unnamed subjective training ingress

The private authority hash is supplied independently in frozen argv:
`--subjective-authority`, `--subjective-authority-sha256`, and
`--subjective-cell`. A leg declaration cannot authorize itself. The authority
binds the entire group roster, paths, manifest/key/table hashes, source counts,
exclusions, producer, selected feature IDs, mode and corrected weights.

`subjective_training_leg.py` and the private native binary module admit all
metadata and label-free ordered keys before payload hashing or loading.
The native path then verifies table bytes and rejects nonfinite selected
features and targets. Protected ancestry is rejected by the existing native
guard. Ordinary groups still pass their existing strict owners and four-source
human allowlist. The new authority does not add a source to that allowlist.

The added group uses stored quality targets (`human_score = -pointwise
distance`), scale one, `withinref,rank`, zero development weight and nominal
weight eight through the existing within-reference acceptance correction.
Its reserved group name is `subjective_rank`. On the registered plain CPU
pair path, exact target ties are counted and contribute no gradient. Other
groups retain their inherited behavior. No magnitude threshold is applied.
All observations of each source share one reference identity. The complete
source/order inventory and excluded families are bound before loading.
No population identities or real manifests belong in this repository.

The converter and any real data access require separate authorization. These
modules alone neither authorize reads nor establish experiment readiness.
