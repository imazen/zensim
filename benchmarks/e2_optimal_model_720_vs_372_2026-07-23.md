# E2 — optimal-model feature validation: does the appended v2-348 block help? (2026-07-23)

**Pre-registered question (the append-only decision):** train the SAME optimal
global model at 720 features (v1-372 `f0..f371` ++ v2-348 `f372..f719`) and at 372
(v1 only, `--max-features 372` cap). If the 720 arm ranks ≥ the 372 arm across the
compression holdouts, the appended v2 features are load-bearing and stay; if not,
they're deprecated-by-masking. This replaces the seed-noisy lab-scale A/B (which
KILLed at epoch-0 scope) with a marginal-at-the-optimum verdict.

## Method

- **Trainer:** `scripts/v_next/e2_train_720_twin.sh` — one recipe, two arms, the
  ONLY diff is `--max-features {720|372}` + `--out`. 2-layer 128-unit MLP, rank+mse
  (`--mse-weight 0.6 --ranknet-weight 0.6`), 200 epochs, early-stop patience 50.
- **Training groups:** `tbig` (2.13M NN-recovered ssim2 ladders) + `safesyn`
  (111k) + `cid201` (CID22 201-ref TRAIN subset, ssim2 — disjoint from the 49-ref
  holdout) — all `withinref,both`; + `kadid`/`tid` as **train-only guards**
  (`val_w=0`, different DMOS target). `--val-policy mean` over the ssim2 groups
  (the default min-of-all pathologically peaked at epoch 0 as the model correctly
  specialized on the ssim2 target and "forgot" kadid's analytic ranking).
- **CID22-49 human MOS never trains** (validation-only rule). It is verdicted
  post-hoc, never an early-stop group.
- **Verdict:** `bake_verdict --regime 720` (the I-1 infra built for this). Both
  arms score on the SAME 720 holdout parquets — the 372 arm reads `f0..f371`, the
  720 arm reads `f0..f719` — so the arms sit on **identical pairs**, differing only
  in whether the model sees the appended block.

**Pre-registered WIN bands (seed 1):**
- compression-holdout mean Δ = **−0.0026** (WIN needs ≥ −0.010) → **PASS**
- worst single-corpus Δ = **−0.0041** (AIC-3; WIN needs no corpus ≤ −0.030) → **PASS**

**Read:** the appended v2-348 block is a clean WIN. It adds **generalizable FR
signal** on the corpora v1 scored weakest — CSIQ +0.112, KonJND +0.035, LIVE
+0.025, all clean holdouts — while being **neutral on every compression-human
holdout** (CID22, AIC-3/4, imazen26 all within ±0.004). Mechanically consistent:
the v2 families (transducers, GMS-deviation, blockiness, spatialized simple-means)
target exactly the analytic/structural distortions that dominate CSIQ/LIVE and are
under-represented in the ssim2-compression training mass. The absolute FR numbers
stay modest (CSIQ 0.58, LIVE 0.51) because the model is compression-specialized by
its training corpus — the v2 block gives it more to work with there, it isn't
FR-trained.
