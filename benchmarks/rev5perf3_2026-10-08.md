Width-indexed readers, reflect-padding and PQ-u16 decoding already read only pixel bytes.

## Pixel-prefix fix

Packed u8 casts now receive only `width * bytes_per_pixel`. Native u16/f32 casts share a private `packed_row` reader: it borrows the aligned pixel prefix and uses the existing bytemuck unaligned-read primitive to copy a single row when necessary. No transfer, alpha, gamut, normalization, reduction, or score arithmetic changes. The fast Rev5 serial RGB branch is untouched.

All seven row gates now pass with their original bit assertions. The initial green run reports `run-heavy: done rc=0 19s | peak-RSS 3.17GiB | min-avail 43374MiB | peak-load 3.75`. Final strict production parity and full all-feature tests are the remaining qualification steps.
