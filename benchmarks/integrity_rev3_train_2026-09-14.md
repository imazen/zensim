## Engineering checks and execution cost

The existing strict trainer now has an explicit Rev3 manifest route while
preserving the original Rev1 recipe. Development is excluded from estimator,
scaler and isotonic calibration. A synthetic full-admission boundary test
intercepts the actual fitting call and verifies those masks and fit-only scaling.
Per-origin weights use one count pass instead of repeated quadratic scans;
the weighting rule is unchanged. Development scoring includes prepared steering,
and unresolved coverage prevents automatic advancement.

Python/Rust parity on all11,472 deduplicated binary inputs is exact: raw tree
outputs0 ULP, probability difference0 and identical activation sets. Fresh
pre-fit extraction took32s; the fit/export/parity/complete-public-validation
command took61s with peak0.81GiB. This is a fast staged experiment workflow,
not a single-image latency measurement. Initial full generation took163s and
retained its input-contract failure rather than presenting a complete corpus.
Six admission tests, script lint and CI-exact Clippy pass. Browser and gauntlet
checks accompany publication. No public Rust API changed in this study.
