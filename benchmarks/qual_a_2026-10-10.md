E33's registered verdict made A (`7cf4cfd9…`) the next production candidate. This run checks A on every release

**Result: A is not release-qualified.** It passes the following: table provenance, the Rust surface (native and
WASM), ZCTH compatibility, G-DIAL, C1–C6, negative tails, raw and served identity, near-identity, and uncached
scalar speed. It fails three:
- G-STEER: 129 of 135 pass, so 6 fail. The all-135 bar comes from the coordinator's QUAL-A brief, which used the
  135-case STEERFIX packet. [The gate map](release_gate_map_2026-10-07.md) defines G-STEER over 143 cases (Broad96,
  owner12 as 4 cases × 3 seeds, KADID JPEG8, full27); the packet has the 4 owner cases once. A fails either way.
- The cached score+map spatial cost (4.1× uncached at 1024², 3.2× at 2048², against ≤ 3×).
- Peak incremental memory with a map: 738,064 KiB at 2048² against 589,824 (+148,240 KiB, +25%). At 1024², A's
  196,908 KiB is 300 KiB (+0.15%) over the 196,608 bar, inside the 248–1,008 KiB spread between the evidence's two
  RSS runs of the same arms (one fresh process per arm). The 2048² failure carries the memory conclusion.

All three models fail the spatial and memory gates, so those failures are not specific to A's weights. The values
differ: C's spatial cost is worse (5.62× at 1024², 3.62× at 2048²). The cost is in the cached score+map path; this
run did not profile which part of that path.
