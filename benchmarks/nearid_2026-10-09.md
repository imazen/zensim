# Near-identity served-score measurement

This lane measures the frozen production seed-0 model (SHA-256 `f803b74c4252952f337abdc0234c2930839d45dddc32ae9b8b5296d6c840f400`) at Rev5, named serving B at Rev1 and named A at Rev1. Each model runs in a separate process. No model bytes, thresholds or default profiles change.

The coordinator fixed the source policy before scoring: eight KADID-10k D1 TRAIN photographs, eight screen/UI and eight graphics sources from canonical-picker `zenjpeg_lossy/train.parquet`. KADID admission reads only its TRAIN bank keys and manifest; picker admission projects only split, origin, rendition, source URL/hash, class and dimensions. Picker origins must end in an even digit. The picker table carries `unknown` classes; folder metadata assigns web screenshots and plots, restricted to origins marked TRAIN by both folder-manifest roles. Existing 512-long-edge renditions are selected before scoring. The recorded `content_image_sha` identifies the original source and is retained as metadata; the original-source mirror is empty, so its bytes are not reverified. Each fetched rendition is pinned against its existing canonical mirror before fetching its recorded R2 URL and checked byte-for-byte by SHA256 afterward. No source pixels are fetched from the checkout. No labels, cached features, protected populations or imazen-26 checkout are opened. Existing admitted reference dimensions are preserved.

Before this source ruling, a SafeSyn contact-sheet inspection opened 49 distinct TRAIN source files. Its packets and contact sheets are retained as superseded exposure evidence; no scoring used that panel. The final KADID/picker panel replaces it before measurement.

`serve_custom_bake --nearid` extends the existing serving example. It calls `BakeScorer::compute` for seed-0 and `Zensim::compute` for the named profiles. Seed-0 diagnostics use canonical research extraction and complete feature inference, including the frozen output spline. `precalibration_score` also records the output without that spline. The counterfactual zeros only consumed reference-only PJND_FRAGILITY IDs 422, 480, 509, 538, 567, 596, 625, 654, 683 and 712. Zero is the requested difference-neutral diagnostic, not the actual identity value of a reference-only signal. Counterfactual values are not served scores or a candidate model.

Every reference has 27 rungs: identity, both signs of a single-channel one-pixel perturbation, six fraction rungs, six uniform-noise amplitudes, seven JPEG qualities and five Gaussian sigmas. Fraction rungs are nested selections from a fixed shuffled pixel order, rounded up to at least one changed pixel, with one channel per selected pixel and alternating signs. A one-LSB step at a byte boundary reflects inward. Noise uses shared uniform quantiles mapped to integers in [-k,k], independently for every RGB channel, then clamps to RGB8. The seed stream is 20261009. JPEG uses the shared zen_io encoder with 4:4:4 and default YCbCr settings; its encoded bytes are retained. Blur uses the pinned zenresize same-size Box pass in sRGB code space plus its Gaussian post-blur, then rounds to RGB8. Changed pixel counts and pixel hashes distinguish effective perturbations from quantized identity.

`prodqual_label_free.py --nearid-summary` reports the maximum nonidentical score, gap from 100, exact nonincrease, and observed first-below crossings at 99/98/95/90. It retains all threshold recrossings and every increase. No interpolation or monotonicity smoothing is used. This finite panel cannot establish mathematical continuity or perceptual accuracy.

The scoped recipe file is `benchmarks/nearid.just`. All builds, data loading and scoring use the coordinator's shared heavy lock and run-heavy. Tool tests verify nested effective perturbations and the real blur's identity/edge behavior. Report controls verify identity exclusion, a deliberately reversing ladder with recrossings, and refusal of an incomplete panel.
