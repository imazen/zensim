# PERF3: Rev5 scoring and retained maps

The queue, fused retained-channel work and horizontal SAT prefixes are on main
(`add2dc77`, `f6348b9c`); main CI run 39124197033 passes every job.
The additive cached-score API and further direct-retention work are reviewed
together. No model, precision, map resolution or oracle threshold changed.

Remaining work within each call is explicit: two of seven owned core planes
still copy; vertical SAT, producer collection and ordered strip/scale/channel
accumulation retain their serial order. Five moment/activity cores write
directly for supported canonical Rev5 queued and one-worker fused walks;
other modes retain the original copy path.

Times below are milliseconds, p50/p95, from the unchanged SPEEDQ first 32 clean
rounds of at most 64, on r7900x with Rust 1.99.1 and no target-cpu=native.
The before binary is the byte-identical PERF2 rebuild; the review binary is
`8fd20366` (compiled source `23ef948e`).
