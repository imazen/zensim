# Rev5 implementation speed ladder — 2026-10-04

**UNQUALIFIED:** resource gates fail; timings are provisional. This ladder
measures intermediate implementation states with one fixed by_v2fy bake
whose revision stamp matches each process. Arithmetic changes between
intermediate Rev5 states are intentional; this is not a model-quality ladder.

The current benchmark harness was compiled against each preserved jj source
snapshot. All source files were restored to the retained implementation before
final gates. The controls use final code at Rev3/Rev4. Three batches interleave
three historical states with Rev3, Rev4 and final Rev5; controls below average
their three batch means. Ten rounds per size/group, one call per arm/round,
three untimed warmup calls. Times include the pipe round-trip. Raw rounds,
execution orders, `uptime`, flags and manifests are in
`/var/tmp/rev5/ladder-matrix/`; builds and hashes are in
`/var/tmp/rev5/ladder/`. Drivers: `build-ladder.py`, `ladder-matrix.py`
under `/var/tmp/rev5`. All heavy commands use the registered 16 GiB / 8-job
wrapper and private targets. ST pins CPU 8; eight threads pin CPUs 8–15.
v3 uses `ZENSIM_MAX_TIER=v3`. Units below are mean milliseconds.
