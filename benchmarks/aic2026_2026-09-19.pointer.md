and what produced them. Analysis: [`aic2026_agreement_2026-09-19.md`](aic2026_agreement_2026-09-19.md).

## Content-overlap audit (run BEFORE first use)

`check_holdout_overlap` (dHash-64), threshold 16. Reports at
`~/tmp/aic2026/audit/` (`aic2026_vs_train_dhash_t16.tsv`,
`aic2026_vs_t0holdouts_dhash_t16.tsv`, + logs).

* **vs our TRAIN corpora** (8,370 distinct sources: safesyn 3,218,
  imazen-26-png-v3 2,639, KonJND-1k 1,008, KonFiG-IQA 1,230, CID22
  `CID22/original` 250, TID2013 25): 59 flags at d≤10, **58 of them against
  `S14_Ref_00.png` alone**, whose dHash is the degenerate `0303030303030303`.
  S14 is a text-document page and the flagged training rows are web
  screenshots, scanned documents and patent pages — the documented
  flat-content false-positive mode. The one non-S14 flag, `S54_Ref_00.png`
  (wristwatch on white) vs CID22-train `2291004.png` (aerial basketball court)
  at d=9, was adjudicated by inspection: unrelated. **No genuine overlap.**
* **vs the existing T0 estate** (CID22-49 + AIC-3 10 + AIC-4 5): global minimum
  **d=15**, zero flags at d≤10. AIC2026 content is disjoint from the eval
  corpora already on the board, so this panel and those are independent reads.
* Residual: dHash is crop-blind. Not auto-quarantined; flags are reported.

## Correctness checks

* **Identity** — all 70 references scored against themselves return exactly
  `100.0` on all six models (`~/tmp/aic2026/check/identity_scores.parquet`).
* **Second route** — 5 random rows rescored for `B` through the
  `zensim_score` example (a different entry point *and* a different PNG
  decoder) agree with `score_pairs_tuner` to the example's 8-decimal print
  precision, which also shows the two decoders produce identical pixels.
* **PNG headers** — all 70 sources and all 9,688 cropped stimuli are 8-bit,
  colour-type 2 (RGB), non-interlaced. No `iCCP`, no 16-bit, no alpha. 9,075
  of 9,688 crops carry an `sRGB` chunk; the 613 untagged ones are scattered
  across every codec (a PNG-writer artifact, not a colour-space difference),
  and the only two files with `cHRM` declare the exact sRGB primaries. Treating
  the whole corpus as sRGB8 is therefore correct, not an assumption.

## Reproduce

```sh
# 1. pairs list (cropped)
#    stimulus \t ref_path \t dist_path, from metrics_cropped.csv + the PTC crops

# 2. six models through the public surface (repeat with fullres_pairs.tsv and
#    --output .../zensim_scores_fullres.parquet for the full-resolution leg)
target/release/score_pairs_tuner \
  --pairs cropped_pairs.tsv \
  --output /mnt/v/output/zensim/aic2026/2026-09-19/zensim_scores_cropped.parquet \
  --threads 8 --profile v0_2 --profile b --profile c --profile d \
  --ensemble r915_y60_h32_ens5=<5 R915_y60_h32_s171*.bin, comma-separated> \
  --ensemble r915_basic228_h128_ens5=<5 R915_basic228_h128_s171*.bin>

# 3. peer implementations on the same pixels
zensim-bench/target/release/examples/peer_metric_pairs \
  --pairs cropped_pairs.tsv \
  --output /mnt/v/output/zensim/aic2026/2026-09-19/peer_scores_cropped.tsv --threads 8

# 4. panel
python3 scripts/aic2026_agreement.py \
  --metrics-cropped /mnt/v/datasets/aic2026/metrics_cropped.csv \
  --metrics-fullres /mnt/v/datasets/aic2026/metrics_fullres.csv \
  --scores-cropped  /mnt/v/output/zensim/aic2026/2026-09-19/zensim_scores_cropped.parquet \
  --scores-fullres  /mnt/v/output/zensim/aic2026/2026-09-19/zensim_scores_fullres.parquet \
  --peer-cropped    /mnt/v/output/zensim/aic2026/2026-09-19/peer_scores_cropped.tsv \
  --out-md        benchmarks/aic2026_agreement_2026-09-19.md \
  --out-json      benchmarks/aic2026_agreement_2026-09-19.json \
  --out-json-full /mnt/v/output/zensim/aic2026/2026-09-19/aic2026_agreement_full.json \
  --n-boot 400

# 5. manifest
python3 scripts/aic2026_manifest.py --dir /mnt/v/output/zensim/aic2026/2026-09-19
```

Builds: `cargo build --release --bin score_pairs_tuner` and
`cargo build --release --manifest-path zensim-bench/Cargo.toml --features zen-decode --example peer_metric_pairs`.
Everything heavy runs under `~/work/zen/scripts/run-heavy --mem 16G --jobs 8`.
