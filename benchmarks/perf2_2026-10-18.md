## What limits threading

The retained map extraction takes the split channel path in `feature_v2.rs`: phase A over three channels, serial retention copies, then phase B. Retention disables both fused channels and the bounded independent-strip queue. Some inner kernels use row bands, but each strip still crosses these barriers. The scalar path can use queued strip jobs. This limits available work even on large images.

Density processes scales and channel contributions in order. The original bin fold was serial. SAT construction retains horizontal and vertical recurrence dependencies; zero fills, retained-plane copies and output allocation add memory traffic. This is verified source structure. Cache misses alone do not prove DRAM bandwidth saturation.

The exact changes reuse the temporary f64 bin canvas, bound combine slices once, and process independent bin rows in 64-row bands with runtime SIMD dispatch once per band. Each pixel retains the original addition/multiply/zero-handling order; returned density and SAT buffers remain independent. The retained-extraction queue/barrier limitation remains.
