## Phase 1: decoder swap (LANDED, commit `3bd88eca`)

The previous V11-372feat extractor (commits `21cd74c` +
`8d7ab78` + `db23006`) used `image::open` and skipped AVIF + JXL.
Replaced the open path in
`zensim-bench/examples/extract_features_372col_omni.rs` with
extension-dispatched decode:

- `.avif` → `zenavif::decode(bytes)`
- `.jxl` → `zenjxl::decode(bytes, None, &[])`
- everything else → `image::open(path).to_rgb8()` (unchanged)

Both codec results pass through a `pixelbuffer_to_rgb8()` helper
(lifted from `zensim-target/src/codec.rs`) that handles either RGB8
or RGBA8 returns, dropping alpha for the latter.

`zensim-bench/Cargo.toml` adds `zenavif` + `zenjxl` + `zenpixels` as
path-deps under the `extract-omni` feature, mirroring the pattern
already used by `zensim-target` in this workspace. No
`[patch.crates-io]` changes required.

Build clean under `cargo build --release --features extract-omni`.

| zenavif | 50 | 0 | 372-feat output, valid feature ranges |
| zenjxl  | 5 | 0 | 372-feat output, valid feature ranges |
