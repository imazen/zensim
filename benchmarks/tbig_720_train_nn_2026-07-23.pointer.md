## How it was built (NN-variant join)

The fleet feature corpus (`tbig_720_features.parquet`, 5,742,660 × 720) and the
target corpus (`bigcodec_hqdedup_traindigits_2026-07-02.parquet`, 2,322,579 rows /
**2,307 refs**, `human_score` = ssim2) share no `encode_sha` — their 372-D features
were extracted by **different decoders**, so an exact fingerprint join hits only
**65.2%** (decoder drift shifts the SAME cell's features past any match threshold).

The NN join recovers the rest: within each reference's ~1,277 fleet variants, the
target cell's true variant is the **nearest** in 372-space (drift ~1e-8 median ≪
inter-variant q-spacing), so nearest-neighbour uniquely identifies it. A distance
**threshold 0.03** keeps it honest — if the nearest variant is too far (cell
genuinely absent from the fleet), the row is **dropped + flagged, never matched to a
wrong cell or fabricated**.

Each output row carries the **fleet's own self-consistent 720** (so `f0..f371` and
`f372..f719` are on the *same* pixels) + the target's `human_score` + `nn_dist`.
