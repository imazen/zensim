# V0_20a IW streaming-integration perf measurement (2026-05-14)

**Commit**: `258e658` (zensim/streaming-side IW feature integration).
**Hardware**: AMD Ryzen 9 7950X (water-cooled, thermal throttling not a factor).
**Build**: `cargo run --release` (default features), NO `-C target-cpu=native`
(per CLAUDE.md benchmarking discipline).

**Bench harness**: interleaved A/B/C/D rounds (zenbench style — back-to-back
ABCDABCD ordering kills thermal/turbo bias; 50 iters per cell, 3 rounds).
Reference source at `/tmp/iw_bench/bench_iw.rs`.

## Results (512×512 8-bit RGB, gradient + low-noise distortion)

| Config | Round 1 | Round 2 | Round 3 | Median | Δ vs OFF |
|---|---:|---:|---:|---:|---:|
| **OFF** (basic+peaks, 228)       | 7047 | 6747 | 7084 | 7047 | — |
| extended only (300, masked)      | 7739 | 7884 | 8012 | 7884 | **+12 %** |
| iw only (300, IW)                | 7950 | 8440 | 7976 | 7976 | **+13 %** |
| BOTH (372, masked + IW)          | 8255 | 8238 | 8420 | 8255 | **+17 %** |

(units = µs/call)

## Key findings

1. **OFF path: zero overhead from the IW additions.** The `OFF` median of
   ~7050 µs/call is consistent with the pre-IW codebase. The
   `need_activity = config.extended_features || config.compute_iw_features`
   gate is a constant-per-call branch in the SIMD hot loop; the branch
   predictor sees a fixed direction and the IW path is fully bypassed.

2. **IW alone costs roughly the same as masked alone** (+13 % vs +12 %).
   Both paths use the same blurred-activity buffer (computed once) and
   the same `ssim_channel_masked` + `edge_diff_channel_masked` SIMD
   helpers (called with the appropriate weight buffer).

3. **BOTH costs only +17 %, not +25 %** — the shared activity-map
   computation is the dominant overhead; the second weight buffer +
   second masked-fn call is cheap on top.

4. **The IW feature count is correct**:
   - OFF emits 228 features.
   - IW-only emits 300 features (basic 156 + peaks 72 + IW 72).
   - BOTH emits 372 features (228 + masked 72 + IW 72).

## How to reproduce

```sh
mkdir -p /tmp/iw_bench
cat > /tmp/iw_bench/Cargo.toml <<EOF
[package]
name = "bench_iw"
version = "0.0.0"
edition = "2024"
[dependencies]
zensim = { path = "/home/lilith/work/zen/zensim/zensim", features = ["training"] }
[[bin]]
name = "bench_iw"
path = "bench_iw.rs"
[profile.release]
opt-level = 3
EOF
# bench_iw.rs source committed at benchmarks/v0_20a_iw_perf_2026-05-14.rs
cargo run --release --manifest-path /tmp/iw_bench/Cargo.toml
```
