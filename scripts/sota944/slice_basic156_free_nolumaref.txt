# The BASIC-156 + FREE-SET slice with the four REFERENCE-ABSOLUTE slots REMOVED
# -- benchmarks/fastclass2_campaign_2026-09-05.md section 2 (the identity fix).
#
# 261 coordinates = scripts/sota944/slice_basic156_free.txt's 265 MINUS
# f926, f931, f936, f941 = LUMA_MEAN_REF, one per scale (named in
# benchmarks/free_features_2026-09-01.md section 4).
#
# WHY, measured (fastclass2 section 2, on the 39-row 944-pools identity probe
# /mnt/v/output/zensim/dfree-2026-09-05/probes/identity_probe_944pools_2026-09-05.parquet):
# the ref==dist feature vector is NOT the zero vector at this width, and the
# contamination is concentrated in exactly these four slots.
#
#   keep set          slots identity-NONZERO   max |value|   max spread over refs
#   156 (basic)                       36          8.103e-04           7.882e-04
#   228 (+peaks)                      60          4.754e-03           4.587e-03
#   265 (+free)                       64          6.883e-01           2.607e-01
#   261 (this file)                   60          4.754e-03           4.587e-03
#   289 (+class-C)                    64          6.883e-01           2.607e-01
#
# All 33 of the other raw-moment slots (f733..f922, the GLOBAL_DMEAN /
# GLOBAL_CGAIN / GLOBAL_CLOSS triples) are identity-ZERO, and so are all 24
# class-C slots. LUMA_MEAN_REF is the ONLY reference-absolute statistic in the
# free set -- it reads the reference's own mean luma, so it cannot vanish when
# ref == dist, and it drags the identity vector two-and-a-half orders of
# magnitude further from zero than everything else in the set combined.
#
# G-ADDR C5 (identity dial in [97.5,100]) and C6 (no grid cell above identity)
# both want the identity dial to be a near-constant of the MODEL rather than a
# function of the image. Dropping these four is the SELECTION form of that fix
# and needs no kernel change: V1FreeExtras::RawMoments still emits them, the
# model simply does not read them, and dead-column pruning removes the lines at
# pack time. (The other form -- emitting a difference-form slot instead -- is a
# kernel change and is registered, not taken, in section 2.3 of the campaign.)
#
