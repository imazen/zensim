## Cycle-7 actionables (refined)

1. **Two real losses to investigate**: HEIC (-0.002, noise-level)
   and JPEG (-0.006, real). Both are JPEG-DCT-derived codecs that
   V0_X *should* model well — investigate why V0_16 underperforms
   ssim2 on JPEG specifically (V0_2 was at 0.9424, V0_16 at 0.9402;
   tiny regression from V0_2 → V0_16 on JPEG).
2. **AVIF_aurora_fast remains a relative weak spot** (V0_16 0.8618,
   ssim2 0.8627, tied; but V0_2 was 0.80 — V0_16 fixed most of it).
   Densifying AVIF training samples further could push this from
   tie → win.
3. **dssim co-training**: the AIC-4 dssim-wins-over-ssim2 finding
   doesn't replicate on CID22. So dssim's value as an auxiliary
   target is corpus-specific; worth experimenting with weighted
   loss but not a slam-dunk.

## Reproducibility

```bash
python3 -c "
import pyarrow.parquet as pq
from scipy.stats import spearmanr
df = pq.read_table('cid22.parquet').to_pandas()
sub = df[df['codec'] != 'Reference']
for codec in sorted(sub['codec'].unique()):
    s = sub[sub['codec']==codec].dropna(subset=['score_zensim_v0_16','score_ssim2_gpu'])
    rv, _ = spearmanr(s['score_zensim_v0_16'], s['human_mos']); rv = abs(rv)
    rs, _ = spearmanr(s['score_ssim2_gpu'],    s['human_mos']); rs = abs(rs)
    print(f'{codec:22s} V0_16={rv:.4f} ssim2={rs:.4f}  Δ={rv-rs:+.4f}')
"
```
